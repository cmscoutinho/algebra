SEÇÃO 1

A teoria em cinco cartões

O essencial para usar o laboratório. O primeiro cartão verifica se uma equação é linear.

Equação linear

Cada variável tem expoente 1, e não há multiplicação nem divisão entre variáveis. Ex.: x + y − 2z = 3. Não lineares: x² − 5x = −6, 3xy + z = 0.

Sistema e solução

Um sistema linear é um conjunto de equações lineares com as mesmas variáveis. Cada equação tem coeficientes, variáveis e um termo independente (sem variável). A solução é o conjunto de valores que satisfaz todas as equações ao mesmo tempo.

Forma matricial

Só os números interessam. A matriz dos coeficientes (incompleta) guarda os coeficientes; a matriz completa (aumentada) inclui também a coluna dos termos independentes.

Classificação

SPD: possível e determinado (uma solução). SPI: possível e indeterminado (infinitas). SI: impossível (nenhuma). Em 2×2, cada equação é uma reta:

Operações elementares

Transformam o sistema em outro equivalente, com a mesma solução:

  • trocar duas linhas: L1 ↔ L2
  • multiplicar uma linha por k ≠ 0: L2 → −L2
  • somar a uma linha um múltiplo de outra: L2 → −2L1 + L2

Substituição e adição usam as mesmas ideias, escritas com as equações em vez da matriz.
